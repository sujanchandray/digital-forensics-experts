Storage Health Check

Read the health log on a hard disk, SSD, USB drive, or memory card, then open a report in the browser on that computer.

This website does not read your disk. Install the program on the computer you want to check.

Download for Windows Download for Mac

Install

  1. Download the file for your computer and unzip it.
  2. On Windows, double-click StorageHealthCheck-Setup.cmd. On a Mac, double-click check-ssd-health.command.
  3. Approve the administrator prompt. The report opens in the browser on that computer.

A stock iPhone cannot run this program. Apple does not allow it to read the phone’s storage health.

What the report shows

  • A health percent from the drive’s own wear and error log.
  • A separate performance line for the slowest response Windows has recorded.
  • Temperature now and the highest temperature recorded.
  • A short note on what those numbers mean.
  • The maker, model, and serial, with a link to that maker’s warranty page. The expiry date is not stored on the drive.
