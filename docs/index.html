QuickStorage
HealthCheck

Read the health log on a hard disk, SSD, USB drive, or memory card. The report opens in the browser on that computer.

Download for Windows Download for Mac

This website does not read your disk. The check runs on the computer after you install it.

Health

A percent from the drive’s own log

Wear and error counts set the health percent. A slow response stays on its own line.

Performance

Kept separate

The slowest response Windows has recorded, labeled as that reading, not the usual speed.

Temperature

Now and highest

The report prints the temperature now and the highest temperature the drive has recorded.

Forecast

What the numbers mean

A short note connects wear, a slow response, and unexpected shutdowns. It does not name a failure date.

Warranty

Not stored on the drive

The report shows the maker, model, and serial, plus that maker’s warranty page. The expiry date is not on the drive.

Install

01

Unzip

Download the file for your computer and unzip it.

02

Run the setup

On Windows, double-click StorageHealthCheck-Setup.cmd. On a Mac, double-click check-ssd-health.command.

03

Approve

Approve the administrator prompt. The report opens in the browser on that computer.

This solution does not support iPhone.
